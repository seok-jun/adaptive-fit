# 현재 상태와 작업 경계 (#2)
기준 main 8e83ae4에는 README와 MIT 라이선스만 추적된다. 이 브랜치에 포함한 제품 결정과 .agentics 연결은 승인된 로컬 세팅이다. 설치 앱, 사용자 데이터, DB, 인증, 네트워크 호출, 테스트, 빌드 설정, 앱 서명 이력은 제품 저장소에 없다. 기존 사용자 데이터 이관은 없다.

사용자는 개인 설치형 앱, 기기 내 공급자별 키, 직접 통신, 지원 모델과 추론 강도 선택, 코칭 한 번과 APK를 요청했다. 코칭 내용은 운동 정보이며 개인 계정 과금이 발생할 수 있다. 키와 운동 내용을 공개 기록 및 로그에서 제외한다. 초기 요청에 기록 이력이 없을 수 있으므로 현재 입력만 근거로 쓴다. 승인 전 제안을 실제 수행으로 기록하지 않는다. 네트워크가 없으면 새 코칭을 받을 수 없다.

현재 PC는 Windows, 기본 Node 20.11.1, Android SDK 36/37과 Android Studio JBR 25가 있다. 프로젝트 전용 빌드 도구 버전과 호환성은 빌드로 확인한다. 실키·실제 폰은 제공되지 않았다. 오프라인 키 없는 자동 테스트, 설치 패키지 검증 및 가능한 에뮬레이터 검증과 사용자 폰에서의 유료 확인을 구별한다. 별도 백엔드, 업로드 배포, 타이머 및 실제 운동 기록 기능은 이번 경계 밖이다.
# 직접 계약과 확인 범위
두 공급자의 개인 키 등록·교체·삭제와 마지막 선택 복원을 제공한다. 키 및 운동 정보는 저장소·로그에 남기지 않으며 테스트 입력은 합성 자료만 쓴다. 첫 유료 요청 전에 보내는 운동 정보와 과금을 공개하고 명시적 동의를 받는다. 구조와 도메인 제약을 검증한 제안은 승인 후에만 계획에 적용한다. 모든 실패에서 승인 계획을 유지한다.
로컬 서명 APK에 JS와 자산을 포함해 개발 서버 없이 실행해야 한다. 실기기·유료 계정별 접근은 미검증 범위를 기록한다. OpenAI는 모바일 키 대신 백엔드를 권고한다(https://help.openai.com/en/articles/5112595-best-practices-for-api-key-safety). 사용자 본인의 설치 앱에서 직접 호출하는 이번 결정에는 실행 중 키가 노출될 잔여 위험이 있다.

# 입력과 표시 기준
추천은 ‘예정’과 ‘추천’ 글자로, 실제는 번호가 붙은 세트 행과 ‘기록됨’으로 구분한다. 무게를 직접 고치거나 구간 반복을 펼치는 동안에는 기록하지 않는다. 횟수를 탭하면 현재 무게와 구간 반복 수를 한 번 전달한다. 다음 입력에서 구간 반복은 접힌 0회다.
| 화면 요소 | Android 구현 | 확인 |
|---|---|---|
| 예정 및 입력 | SetInputView | 8회·7회 단일 탭, 무게 수정, 15회 중 5회 |
| 실제 및 종료 요약 예시 | MainActivity, SessionSummaryView | 빈 상태와 실제 합성값, 기록 전후의 위계 |
| 상태와 접근성 | 색상·치수 리소스, 기본 Button·Switch·Spinner | 48dp, 대비 4.5 이상, 큰 글꼴, 접근성 역할·값·선택 |
일반 본문은 16sp, 수치와 구역 제목은 20sp 이상이다. 배경과 표면은 밝게, 본문은 짙은 녹색, 오류는 짙은 적색을 사용한다. 선택한 횟수에는 표시 기호와 선택 상태를 함께 주고 누름은 리플로 표시한다. 합성 화면의 입력 범위는 예시값으로 제한하며 #5는 표시할 횟수 후보와 기록 콜백을 제공한다.
Independent Review: REQUIRED. #5가 소비할 입력 계약과 접근성 상태를 독립 검토한다.

## API 36 검증 결과
JDK 17, API 36 휴대폰 에뮬레이터(1080 × 2400, 420dpi), 단위 테스트·lint·debug APK·release AAB 통과. lint 오류 0개, 기존 SDK 관련 경고 2개와 코드에서만 생성하는 입력·기록 뷰의 레이아웃 편집기 생성자 경고 2개.
- 시작 시 빈 요약을 확인했다. 8회 한 탭과 7회 한 탭으로 각각 한 건이 추가되고 선택 상태가 이동했다. 빈 무게로 누르면 오류 문구가 나오고 건수는 유지됐다.
- 95kg으로 수정하고 마지막 5회를 고른 뒤 15회를 누르면 실제 95kg × 15회, 전 구간 10회·구간 반복 5회로 표시되고 스위치가 꺼졌다. 구간 10회를 고르면 총 7회 버튼이 비활성화됐다.
- 기본 배율의 입력 대상은 가로·세로 각각 126px(48dp) 이상이었다. 글꼴 200%에서 횟수 버튼은 한 열에 배치되고 추천·숫자·단위를 포함한 전체 텍스트가 표시됐다. 흰 표면에서 본문 14.99:1, 보조 문구 7.22:1, 오류 7.67:1, 비활성 버튼의 흰 글자 6.87:1이다.
- TalkBack 16.0 서비스 연결 상태에서 키보드 초점이 무게 입력란 → 구간 스위치 → 7회 버튼으로 이동했고, 실행 후 접근성 노드에서 Button, ‘✓ 7회’, selected=true를 확인했다. 한국어 합성 음성 청취는 미검증이다.
- 독립 코드 검토의 선택기 값, 오류 안내, 종료 피드백 본문 지적을 반영한 뒤 재검토를 통과했다.

## #5에서 재사용
SetInputView 생성자에 기본 무게(BigDecimal), 추천 횟수, 양의 정수 횟수 후보, OnSetListener를 전달한다. 예시의 네 후보를 다른 목록으로 바꿀 수 있다. 콜백에서 받는 구간 반복은 총횟수에 포함된다. SetRecordView에는 실제 결과를, SessionSummaryView.show에는 실제 세트 수와 표시할 피드백을 전달한다.
